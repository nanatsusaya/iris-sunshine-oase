# Documentation

The knowledge base for the rebuild of **iris-sunshine-oase.de** — the website of
Iris’ Sunshine Oase, a tanning and cosmetics studio in Herxheim bei Landau (Pfalz).

This folder is the project's **single source of truth**. What is not written down here does
not exist for the purposes of the rebuild.

## How the documentation is split

Each artefact answers one question, and they are separated by how often they change — so no
two files compete to answer the same thing.

| Where | Answers | Changes |
|---|---|---|
| [`../CLAUDE.md`](../CLAUDE.md) | How is work done here? | rarely |
| [`adr/`](adr/README.md) | What was decided, and why? | append-only |
| [`STATUS.md`](STATUS.md) | Where do we stand? | often |
| [`business-facts.md`](business-facts.md) | What are the studio's address and contact details? | rarely |
| [`recurring-tasks.md`](recurring-tasks.md) | What comes due on a calendar rather than on a change? | rarely |
| [`meta/agent-collaboration-log.md`](meta/agent-collaboration-log.md) | Why does the way we work look like this? | occasionally |
| GitHub issues | What is to be done? | continuously |

### [`adr/`](adr/README.md) — decisions

Architecture Decision Records, numbered and normative. An `Accepted` ADR is binding and
immutable except with logged owner authorisation. **`Accepted` means decided, not built** —
implementation progress lives in [`STATUS.md`](STATUS.md).

### [`meta/`](meta/agent-collaboration-log.md) — how we work, and why

The ADRs record *what* was decided. The collaboration log records *why the way we work looks the way it
does*: owner corrections and their rationale, workflow experiments, and the mistakes that produced a
rule. A rule whose origin is lost gets quietly dropped by the next session that finds it inconvenient.

### [`content/`](content/README.md) — the old site's texts

Every text of the old site, extracted from the WordPress export. Because `Archive/` is not
part of the repository, this is the **only versioned source** of the old content.

Generated by `tools/extract-wp-content.mjs`. Do not edit by hand — correct the generator and
re-run it. **The page text here is German and stays German**: it is source material, a record
of what the site said, not documentation.

The page files under `content/pages/` keep their **German slugs** (`ueber-uns.md`, `impressum.md`)
while everything around them is English. They are identifiers of old-site URLs, not documentation
names, and the redirect table in [`content/urls-and-redirects.md`](content/urls-and-redirects.md)
maps them — renaming them would break the mapping that file exists to record.

> **`docs/content/` is not `src/content/`, and confusing them is the one expensive mistake this
> folder allows.** `docs/content/` is a record of what the **old** site said, nine years old,
> undated and unconfirmed. `src/content/` is the **authority** for what the new site says. A price
> read out of `docs/content/` and rendered as current is exactly the defect class this project
> exists to remove.

## Target picture

| | |
|---|---|
| Technology | Astro 7, statically generated (scaffolded 2026-07-19) |
| Content | structured data (prices, opening hours) instead of layout blocks |
| Maintenance | through GitHub issues, worked by an agent |
| Languages | German by default, English as an additional locale |
| Preview | GitHub Pages, updated from `main`, `noindex` until go-live |
| Hosting | GitHub Pages; domain and DNS stay at netcup (decided 2026-07-18, ADR 0006) |

Two guardrails follow from this, and they explain most of the decisions here:

**The repository stays small.** It is cloned afresh for every ticket, so every megabyte costs
time on every ticket — permanently, not once. No raw material, no binary ballast.

**The documentation is self-supporting.** An agent working a ticket has this repository and
nothing else: no conversation history, no memory of earlier sessions, no access to the
archive. Whatever it needs to know has to be in `docs/`.

## What the archive holds, and where it is

`Archive/` (roughly 600 MB) is excluded via `.gitignore`: image material with undocumented
usage rights, and a database export containing third parties' personal data. Details in
[06-media-inventory.md](analysis/06-media-inventory.md).

> The repository is therefore **not a backup of the old site**. Securing and versioning the
> archive is the owner's responsibility and deliberately outside this project.

## State

Survey taken 2026-07-18. The old site was online at that point, its content current as of
May 2020, its opening hours maintained through winter 2024/25.
